# Security Policy

## Supported Versions

We actively provide security patches and updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of our application and users seriously. If you believe you have discovered a vulnerability, please report it responsibly so we can resolve it before disclosure.

### How to Report
- **GitHub Private Vulnerability Reporting (Recommended):** Open a private security advisory directly at [`https://github.com/ratanaknoch/IP-Portal/security/advisories/new`](https://github.com/ratanaknoch/IP-Portal/security/advisories/new).
- **Direct Contact:** Alternatively, email your findings to the portal administrator at `ratanaknochmunny@gmail.com`.
- **Do not open public GitHub issues** for security vulnerabilities to protect all users until a fix is deployed.

### What to Include in Your Report
To help us triage and patch the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept (PoC).
- Affected files, endpoints, or components (e.g., Firestore rules, auth flow, backend routes).
- Suggested mitigations or fixes, if available.

### What to Expect
- **Initial Response:** You will receive an acknowledgment within 48 to 72 hours of your report.
- **Triage & Status Updates:** We will notify you once the issue has been validated and keep you updated on progress towards a fix.
- **Public Disclosure:** Once a patch is released, we will coordinate public disclosure and credit your contribution if desired.
